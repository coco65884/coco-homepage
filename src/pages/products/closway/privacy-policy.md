# プライバシーポリシー

最終更新: 2026 年 5 月 8 日

本ポリシーは、coco (以下「当方」) が開発・配布する iOS アプリ「Closway」(以下「本アプリ」)
におけるユーザー情報の取り扱いについて定めたものです。

## 1. 取得するデータ

本アプリは以下のデータをユーザーの操作により端末上に保存します。

- ユーザーが撮影・選択した服の画像 (背景透過版を含む) — 端末内 (アプリ専用領域) にのみ保存します
- 画像から自動抽出または手動入力された属性 (ジャンル・フィット・系統・色情報・ブランド等) — 端末内 SQLite データベースにのみ保存します
- 身長・体型などのプロフィール情報 (任意入力) — 端末内 SQLite に保存します

本アプリはアカウント作成を要求せず、上記データはユーザー本人の端末を出ません (例外は次項 2)。

## 2. 第三者への送信

本アプリは以下の限定的な目的で外部サービスに通信します。

- **服属性の AI 抽出**: ユーザーがカード追加・編集時に AI 抽出機能を利用すると、対象の画像 1 枚を HTTPS 経由で当方が運用する Cloudflare Workers の API に送信します。Workers は Google の Gemini API に画像を中継して属性 JSON を取得し、ユーザーに返却します。画像とレスポンスは Workers に保存されません (一時的な処理メモリ上のみ)。Gemini API の利用規約・データ保持ポリシーは Google の定めるところに従います。
- **天気情報 (任意)**: コーディネート提案で気温に応じた絞込みを行う場合、Open-Meteo ([https://open-meteo.com/](https://open-meteo.com/)) に緯度・経度を送信して当日気温を取得します。位置情報は端末からは取得せず、既定の東京駅座標を使用します。

これら以外の外部送信は行いません。広告 SDK・解析 SDK は組込んでいません。

## 3. 通信の保護

すべての外部通信は TLS (HTTPS) で暗号化されます。Workers への接続にはアプリに埋め込んだアクセストークン (X-App-Secret ヘッダ) を用いた簡易認証を実装しています。

## 4. データの削除・端末外への持ち出し

端末内に保存されたすべてのデータ (画像・属性・プロフィール) は、本アプリを iOS からアンインストールすることで完全に削除されます。クラウドへの自動同期は行っていないため、当方サーバ上にユーザーデータは残りません。

画像個別の削除はアプリ内のカード詳細画面から、属性個別の編集はカード編集画面から可能です。

## 5. 子どもの利用

本アプリは 13 歳未満を対象としていません。13 歳未満の方が利用する場合は保護者の同意の下でご利用ください。

## 6. 本ポリシーの変更

本ポリシーは法令の改正・機能追加に応じて改訂することがあります。重要な変更がある場合はアプリ内またはストア説明欄でお知らせします。
